# Проект «Секреты Темнолесья»
Цель проекта — изучить влияние характеристик игроков и их игровых персонажей на покупку внутриигровой валюты «райские лепестки», а также оценить активность игроков при совершении внутриигровых покупок

# Стек
SQL
PostgresQL
DBeaver
CTE
Подзапросы

# Общие выводы и рекомендации
По результатам анализа не выявлено существенной зависимости расы от количества покупок игрока, т.е. игроки покупают эпические предметы независимо от расы. Однако, имеется высокая доля платящих игроков среди игроков с расой «Люди», такие игроки больше совершают покупок эпических предметов за реальные деньги. 
Также выявлено, что наиболее популярным эпическим предметом является «Book of Legends» (около 77% от общего числа покупок), менее популярным предметом является «Bag of Holding» (около 21% от общего числа покупок).
Возможно, необходим дополнительный анализ:
- покупок игроков, в т.ч. за реальные деньги, в разрезе различных скиллов игроков
- дополнительный анализ группы игроков с «высокой частотой» покупок, для выявления зависимостей таких покупок и возможного сходства по расам, скиллам, эпическим предметам.
- какие эпические предметы наиболее часто покупают платящие игроки
